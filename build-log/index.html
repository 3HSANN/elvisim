How I built a lab bench in about two hours.

I set the requirements, checked every version against my own lab, and caught what was wrong. Claude Opus 5.5 wrote the code. Here's how it went, in order.

17 Nov · Evening

From the practice script to a breadboard

The first version was a flat bench with a DMM and a scope. It worked, but it didn't feel like the lab. The real skill is wiring, so I asked for a breadboard where I drag every wire myself.

  • Breadboard strips, header pins and DMM jacks are all connection points
  • Wires join points into nodes; a circuit solver works out every voltage
  • Mistakes behave like the real board: shorts trip the supply, a powered ohmmeter reads "Err"

18 Nov · 9:10 pm

62 checks, one real bug

Every reading was checked against hand calculations, along with the fault cases, wiring with the mouse in 3D and flat view, and speed. They all passed, but an extra check at low frequencies found a real bug, described below.

22 Nov · Practising

Using it taught me what to add

My first builds were wrong: I wired nodes down columns instead of across rows, and measured current with the black probe on the wrong end of R2. Those mistakes became features.

  • Guided setups for I1–I3, Voc, Isc, Rth, τ and AC phase
  • A separate channel for each cursor, so dT can be measured between Vs and Vc, as in ELVISmx

The bug worth writing down

Numerical methods
Symptom

At 50 Hz the capacitor's time constant read 0.414 ms, matching theory. At 1–10 Hz the same circuit read 0.5–0.6 ms. The circuit hadn't changed, so the error had to be in the simulation.

Cause

The transient solver split each period into a fixed 1,600 steps. At 1 Hz that's 0.625 ms per step, longer than τ itself, so the curve was smeared out.

Fix

Before simulating, measure the resistance each capacitor sees and set the step to Δt = τ_min / 40. τ is now correct from 1 Hz to 100 kHz. Precomputing the solver terms made it about 10× faster too.

How the simulation works

Under the bench
1 · Nodes

Union-find

Each breadboard row, rail, header pin and jack is a point. Strips and wires merge points into nets, so "is this the same node?" is a single lookup.

2 · DC

Nodal analysis

Supplies fix their net's voltage, and resistors and the DMM's 0.1 Ω shunt fill a conductance matrix solved by Gaussian elimination. The ohmmeter injects a 1 mA test current.

3 · Transient

Backward Euler

Each capacitor becomes a conductance C/Δt plus a history current, stepped through several periods until it reaches steady state. The scope reads the last period.

4 · Faults

Current limits

If a supply would need more than its limit (0.5 A for ±15 V), the bench reports an overload instead of showing an impossible reading.
